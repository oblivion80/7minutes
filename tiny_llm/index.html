What should come next?

The model is a mathematical function. Four input numbers go in, and four next-word probabilities come out.

REPRESENTING WORDS WITH NUMBERS

First: one-hot encoding

The model receives numbers, not words. We represent each word with four variables: x₁ belongs to Apples, x₂ to are, x₃ to green, and x₄ to red. The selected word’s variable is 1, and all the others are 0.

Why “one-hot”?Exactly one position is “on” (1), while the other three are “off” (0).

THE LINEAR FUNCTION

Four inputs become four scores

Each score is a linear function—the same kind of function used in school mathematics, but with four input variables.

f1=w11 · x1 + w12 · x2 + w13 · x3 + w14 · x4
f2=w21 · x1 + w22 · x2 + w23 · x3 + w24 · x4
f3=w31 · x1 + w32 · x2 + w33 · x3 + w34 · x4
f4=w41 · x1 + w42 · x2 + w43 · x3 + w44 · x4
In our model: Exactly one of x₁, x₂, x₃, x₄ is 1 and the others are 0. So each score f is simply one selected weight.
SOFTMAX

Scores become probabilities

First raise e (about 2.718) to each score. Then divide every result by the same denominator D.

y=softmax(f₁, f₂, f₃, f₄)
D=ef₁ + ef₂ + ef₃ + ef₄
y1 = ef1Dy2 = ef2Dy3 = ef3Dy4 = ef4D
Why is it called soft-max?

The exponential magnifies the largest score, like a maximum. But it is “soft”: it does not keep only one winner. Every word gets a positive probability, and the four probabilities add to 1.

y = F(x) — the whole model is a function. Input x goes in and output y comes out. Changing the input or a weight changes the output, just as with functions in calculus.
